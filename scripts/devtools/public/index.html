DEV TOOLS

Local-only utilities for inspecting the Nostalgex channel rotation and Plex library health. Not shipped in the app.

SCHEDULE EXPLORER

Search every airing across all channels for the past 7 + next 7 days. Validates that titles you expect to see are actually in rotation, and confirms the deterministic algorithm is putting them in the right slots.

→ Past 7d / Next 7d · search by title · ~5k airings

CHANNEL POOLS

Inspect which titles each channel is allowed to play, plus the rules that produced the pool. Use this to debug "why isn't X on channel Y?" — see the pool size, decade/genre breakdown, and the filter rules side-by-side.

→ One channel at a time · rule summary · pool stats

CHANNEL MEMBERSHIPS

Inspect the TMDB membership manifest — which shows are claimed for which channels, by curated exemplar or by TMDB's recommendation/similar graph. Use this to debug claims, find conflicts, or check why a specific show landed where it did.

→ Per-channel claims · show lookup · multi-channel conflicts

LIBRARY AUDIT

Scans every movie / episode in your Plex library and flags files most likely to cause tvOS playback issues — no audio track, lossless audio AVPlayer can't decode, MKV containers, HEVC 10-bit, AV1, wrong default language, very high bitrate.

→ Grouped by issue type · severity ranked

CHANNEL COVERAGE

Every item in your library and how many channels pull it in. Finds orphans (items in zero channels) and groups them by the most likely reason: no TMDB match, no genres, no year, or a rule the tool can't evaluate. Type any title to see exactly which channels carry it.

→ Orphans by reason · thin channels · "where is X?" search · lower bound, not device truth
